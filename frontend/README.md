# FC Predictor-Ahbab

A premium, interactive, and gamified web application for predicting the FIFA 2026 World Cup tournament outcome. Powered by a Poisson + Elo-based machine learning prediction engine on the backend, this React-based single-page application allows users to customize group stage standings, plan knockout round bracket outcomes, manage squad ratings/biases, and visualize simulated championship probabilities.

## Features
- **Interactive Group Stage**: Customize and re-rank group stage pools.
- **Dynamic Knockout Brackets**: Hand-pick knockout stage winners and let the ML engine automatically resolve subsequent rounds.
- **Advanced Gamification**: Tweak team Elo ratings, simulate customized squads, and adjust champion-favourite biases.
- **Real-Time Data Visualization**: Premium charts and visual brackets updating in real-time.
- **Modern Tech Stack**: React, TypeScript, TailwindCSS v4, Vite.

## Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (LTS version recommended).

### Installation
Install the project dependencies using your preferred package manager (pnpm, npm, or yarn):
```bash
npm install
# or
yarn install
```

### Running the App
Start the local development server:
```bash
npm run dev
# or
pnpm dev
# or
yarn dev
```

Build the app for production:
```bash
npm run build
# or
pnpm build
# or
yarn build
```
